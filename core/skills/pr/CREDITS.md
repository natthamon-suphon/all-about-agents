# Credits

This portable PR-body skill adapts
[Matt Pocock's pr skill](https://github.com/mattpocock/skills/blob/5beb35b040e3de97e54fa9e386d7e42d15c295c2/skills/engineering/pr/SKILL.md).

Matt's source credits Dex Horthy of [HumanLayer](https://github.com/humanlayer)
for the original framing.
The summary, before/after evidence and merge-danger framing retain that
attribution.

This adaptation honors repository templates, permits a plain summary for a
small change and separates drafting from publication authority. The upstream
credit is historical attribution, not an installed skill dependency.
